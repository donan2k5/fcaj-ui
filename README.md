# FCAJ Tech Event Platform – UI

Static HTML UI mockups (Tailwind CDN) for the FCAJ Đà Nẵng tech event platform.
Design rules: `cloud_enterprise_events/DESIGN.md`.

Open `index.html` to browse every screen (Web / Mobile screenshots / live mobile preview).

| Folder | Screen |
|---|---|
| 01–05, 17, 18 | Public: home, event detail, register popups, leaderboard, sold-out states, about |
| 07–09 | My account: profile, my events (status tabs), event detail / QR |
| 06, 10–15 | Admin: overview, events, speaker review, attendees, points, settings, edit event |
| 16 | Phone check-in QR |

Each folder has `code.html` and `screen*.png` screenshots.
